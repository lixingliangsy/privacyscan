# PrivScan — Use Cases

### SaaS / web apps
- **Pain:** Cookie banners and trackers drift after marketing launches.
- **How PrivScan helps:** Scan practices, map likely Art. 6/7 gaps, export a remediation checklist.
### Agencies
- **Pain:** Client sites need a repeatable privacy readiness pass.
- **How PrivScan helps:** Run per-URL checks with article-referenced issues.
### EU / UK market entry
- **Pain:** Founders lack a concrete gap list before DPO review.
- **How PrivScan helps:** Privacy readiness score + prioritized fixes.
### Mobile / hybrid
- **Pain:** SDKs add trackers without product awareness.
- **How PrivScan helps:** Describe data practices; get consent and collection flags.

ref: GDPR Art. 6 (lawfulness) · GDPR Art. 7 (consent)
